# 校园失物招领平台（Web 前端版）

《Web开发实践》课程个人项目（课程号 07100130）
学号：2500702201　姓名：付桂豪　计算机2502班

## 项目简介

面向本校学生的失物招领单页面应用：失物/招领信息的集中发布、检索与认领状态管理。
数据使用本地存储与演示数据，不涉及外部敏感数据。

## 技术栈

- HTML5 + CSS3 + JavaScript（ES6+）
- Vue 3（组合式 API）+ Vite 7
- vue-router 4（路由）
- VS Code（开发）+ Git（版本管理）+ 静态托管平台（部署）

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 登录认证 | 本地会话模拟、表单校验 |
| 信息发布 | 失物/招领发布与编辑 |
| 检索浏览 | 关键词搜索、分类筛选、分页 |
| 状态流转 | 待认领 → 认领中 → 已完结 |
| 统计看板 | 分类占比、近 7 日趋势 |

## 运行方式

```bash
npm install       # 安装依赖
npm run dev       # 本地开发，浏览器访问 http://localhost:5173
npm run build     # 构建产物输出到 dist/
npm run preview   # 本地预览构建结果
```

## 目录结构

```
src/
├── main.js          # 应用入口
├── App.vue          # 根组件（导航栏 + 路由视图）
├── router/          # 路由配置
├── views/           # 页面层
├── components/      # 组件层
├── store/           # 状态与数据层
├── utils/           # 校验、脱敏、存储工具
└── data/            # 本地演示数据
```
